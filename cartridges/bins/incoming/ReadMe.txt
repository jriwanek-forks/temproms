These images are for use with a modern PCJr cartridge that uses AT28C256 EPROMS.  Each image is 32 KB in length, with the exception of the Lotus123 images.  Each is 64K that must be split across 2 EPROMS in a cartridge as there are two cartridges for Lotus123 (along with the disk software specific to the PCJr version).  Otherwise, if two images have the same name, they are the two ROMS in a single cartridge.  The address of the ROM is specified in the filename. Note that these images are not necessarily exact dumps of the original ROMS from the cartridge as many used repeating address segments for copy protection.  As a result, some images repeat the cartridge ROM contents multiple times.
